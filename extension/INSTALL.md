# LinkedIn Outreach Assistant — Install Guide

## Step 1: Open Chrome Extensions
1. Open Google Chrome
2. In the address bar, type: `chrome://extensions` and press Enter
3. In the top-right corner, turn on **Developer mode** (toggle switch)

## Step 2: Load the Extension
1. Click the **"Load unpacked"** button (top-left)
2. Browse to the folder containing these files: `linkedin-outreach-extension`
3. Select the folder and click **Open**
4. The extension "LinkedIn Outreach Assistant" will appear in your list ✅

## Step 3: Pin It (Optional)
1. Click the puzzle piece icon 🧩 in the Chrome toolbar
2. Click the pin icon next to "LinkedIn Outreach Assistant"

---

## How to Use

### Sending an Outreach Message
1. Go to any LinkedIn profile (e.g., `linkedin.com/in/someone`)
2. The **Outreach Assistant panel** appears on the right side of the screen
3. Pick a template from the dropdown — variables like `{{firstName}}` auto-fill from the profile
4. Edit the message if needed
5. Click **"Fill Message Box"** — the extension pastes the message into LinkedIn's compose box
6. **You click Send** (the extension never sends automatically)
7. Click **"Log as Sent + Schedule Follow-up"** to track the contact

### Follow-up Reminders
- Set the number of days before a follow-up reminder (default: 3 days)
- Chrome will show a desktop notification when it's time to follow up
- Click the notification to open the person's LinkedIn profile

### Managing Templates
- Click the **Templates** tab in the panel
- Edit existing templates or create new ones
- Use variables: `{{firstName}}`, `{{lastName}}`, `{{company}}`, `{{headline}}`

### Tracking Contacts
- Click the **Tracker** tab to see everyone you've messaged
- Mark contacts as **Replied** or remove them

## Tips
- **Move the panel** by dragging the blue header bar
- **Minimize it** by clicking the − button (a floating icon appears instead)
- All your data stays in your browser — nothing is sent to any server

## Troubleshooting
- **Panel not appearing?** Refresh the LinkedIn page after installing
- **"Could not find message box"?** Open a LinkedIn chat/message window first, then click Fill
- **Notifications not showing?** Allow notifications for Chrome in your system settings
